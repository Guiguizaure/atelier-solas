# Atelier Solas

Demo site for a **fictional** made-to-measure atelier in Marseille, direction « Déboutonné ».
Concept, design and development by Guillaume Salle (Webjuno). Portfolio project.

```sh
pnpm install
pnpm dev        # http://localhost:3000
pnpm typecheck && pnpm lint && pnpm build   # static export in out/
```
